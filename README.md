# Customkeytimer
A simple and customizable countdown timer for Windows

* Select a keyboard key then set a countdown duration time.
* This timer can be positioned anywhere on your screen and will begin timing down any time you tap the designated key.
* Ideal for games, productivity, shortcuts/cooldowns, or any scenario that requires a quick visual timer without interrupting what you're doing.
